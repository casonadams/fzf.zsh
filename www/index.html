Prerequisites

        
Required & Recommended Binaries

        
fzf.zsh configures shell completions, widgets, and preview pipelines, but requires the fzf binary. Install optional companion tools to unleash fast search and rich previews.

      


      

        

          
Required

          

            
fzf ↗

            Core Engine
          

          
Interactive command-line fuzzy finder powering all interactive menus, file pickers, and widgets.

          
brew install fzf or apt install fzf

        


        

          
Recommended

          

            
fd ↗

            Fast Search
          

          
Fast, colorized, user-friendly alternative to find with smart ignore rules (.gitignore).

          
brew install fd or apt install fd-find

        


        

          
Recommended

          

            
bat ↗

            File Preview
          

          
Cat clone with syntax highlighting, line numbering, Git diff badges, and automatic themes.

          
brew install bat or apt install bat

        


        

          
Recommended

          

            
eza ↗

            Tree Preview
          

          
Modern, maintained replacement for ls featuring recursive directory tree previews with file type styling.

          
brew install eza or apt install eza

        


        

          
Fallback

          

            
ripgrep ↗

            Fast Search
          

          
High-performance line-oriented search tool used automatically if fd is not found on your system.

          
brew install ripgrep or apt install ripgrep

        


        

          
Fallback

          

            
tree ↗

            Tree Preview
          

          
Standard Unix recursive directory tree viewer used automatically if eza is not installed.

          
brew install tree or apt install tree

        

      

    

  


  

    

      

        
Quickstart

        
Install in Seconds

        
Compatible with all major Zsh plugin managers. Highly recommended with zload for instant startup.

      


      

        
        
        
        
        
      


      

        
# Add to ~/.zshrc
zload casonadams/fzf.zsh

      


      

        
# Add to ~/.zshrc
zinit light casonadams/fzf.zsh

      


      

        
# Clone into custom plugins
git clone https://github.com/casonadams/fzf.zsh ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/fzf

# Add to plugins in ~/.zshrc
plugins=(... fzf)

      


      

        
# Add to ~/.zsh_plugins.txt
casonadams/fzf.zsh

      


      

        
# Clone repository
git clone https://github.com/casonadams/fzf.zsh ~/.fzf.zsh

# Source in ~/.zshrc
source ~/.fzf.zsh/fzf.plugin.zsh
